# Boss Clock

A simple time clock mockup for Garcia & Son Concrete.

## What is included

- Ten named employees: Garcia Employee #1 through #10
- Select an employee, then clock in or out
- Small crew totals for today and the week
- Separate public admin page at `/admin.html` with a mock login and simple monitoring table
- Responsive layout for phones and desktop
- Yellow hazard-diamond brand mark and restrained industrial styling

This is intentionally a front-end mockup. Data resets when the page is refreshed; the admin login is intentionally a mock and there is no authentication or database yet.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
